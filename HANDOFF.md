Открой эту папку как проект и попроси прочитать `HANDOFF.md` и `README.md`.

## Что это
Сайт FinStarter (white-label платформа для инвестиционных компаний, Itransition). Три страницы в `site/`:
`index.html` (главная), `how-it-works.html`, `contact.html`. Чистый HTML/CSS/JS, без сборки — открывается двойным кликом.

Макет: Figma `cYq7eMIYNFVB2I0VSWinVc` (главная — node 14-12173, компоненты 14-11385, дропдаун 14-12199, How it works — 21-34785).
Figma MCP на Starter-плане упирается в лимит; данные брались через REST API с personal access token (владелица даёт токен при необходимости; после работы токен удалять).

## Hero (v34)
- Картинка hero — не одна PNG, а сцена `.hero__scene` 1120×550 (`index.html`): CSS-свечение `.hero__glow` (эллипс «Ellipse 7» из Figma, радиальный #1677FF→белый) + 6 карточек `assets/hero/*.png`,
  выгруженных из Figma по отдельности (node 31-21809, каждая с тенью; позиции — render bounds карточки в % от слота, порядок слоёв как в Figma). Старый `hero-collage.png` удалён (копия в `backups/`).
- Анимации (`styles.css`, блок после `.hero__fade`; JS — два последних блока `site.js`): свечение «расцветает» при загрузке, дальше дышит цветом синий↔голубой (`@property --glow`, 8 с);
  текст → кнопки → карточки появляются лесенкой (`hero--in` ставится после decode картинок, не позже 1.5 с); при скролле сцена гаснет, а слои идут с разной скоростью (`--hero-p` × `--depth`: свечение стоит, панели чуть, маленькие карточки быстрее всех).
- Белый фейд снизу `.hero__fade` — на всю ширину (в Figma 1440 px — на 1920 оставлял резкий правый край); `.hero { overflow: clip }` режет тени карточек по краю hero, как фрейм в Figma.
- Общий reveal при скролле: `.fx` / `.fx--in`, список селекторов в `site.js`; карточки компаний и роадмапы оставлены со своей анимацией. `prefers-reduced-motion` отключает всё.
- Локальный preview на Windows: `.claude/launch.json` → `tools/serve.ps1` (сервер на PowerShell, порт 8765).

## Принципы, о которых договорились
- Десктоп 1920 — 1 в 1 по Figma; странности макета не «чинить» без просьбы.
- Общие стили `site/styles.css`; адаптив только в `site/responsive.css` (≤1280 / ≤1024 / ≤900 бургер / ≤768 планшет / ≤640 телефон). Планшет и телефон проверены по комментариям владелицы (v16–v21).
- Общее поведение в `site/site.js` (бургер, дропдаун, модалка Book a Demo, FAQ-аккордеон, count-up, slide-in карточек, роадмапы «24 months»). Страницы: `how-it-works.js`, `contact.js`.
- Роадмапы «24 months» (`.rmap` в `index.html`/`styles.css`): позиции — месяцы на шкале 24 (`--at`, `--from/--to` в inline-стилях), раскладка чисто на calc(); линия — один элемент с полным градиентом (у FinStarter: cyan→blue до Launch, дальше зелёный, растворяется в фон), кольца берут цвет линии в своей точке через color-mix(), при ховере растут; свечение только у линии FinStarter (мягкое, размытая копия линии); JS только запускает анимацию и клампит наезжающие подписи на узких ноутбуках. ≥1025 — горизонтально, ≤1024 — две вертикальные колонки на одной шкале. Позиции этапов (1/2/4 и 2/5/17/19.5 мес.) взяты «на глаз» с макета владелицы — Figma REST отдавал 429 (Retry-After ≈ 35 ч), макет не выгружался.
- Кнопки Book a Demo / Talk to our experts / Send — чёрные с rainbow-обводкой (`.btn--dark`), белая `.btn--white`, контурная `.btn--outline`.
- Живой WebGL-градиент `liquid.js` пока убран со всех страниц по просьбе владелицы («доработаем потом»). Файл `site/liquid.js` и стили `.liquid` в `styles.css` оставлены; вернуть — добавить `<script src="liquid.js" defer>` и `<canvas class="liquid" …>` первым элементом в `.hero` / `.banner` (параметры были: data-bg="#ffffff" data-colors="#b3f3ff,#bfd6ff,#dcefff,#f2faff" data-speed="0.35" data-grain="0.12" data-strength="1.2"; на баннере colors #a8f0ff,#b5cfff,#d6ecff,#f2faff, speed 0.4, strength 1.3).
- Шапка «стеклянная» (72% белого + blur на `.nav::before`), sticky; вверху страницы прозрачная, стекло появляется при скролле. Ховеры меню и ссылок футера — #1677FF.
- Тексты для 8 пунктов бокового меню на How it works и ответы FAQ — черновые, написаны мной; владелица может заменить.
- Eyebrow «HEADER» на How it works — заглушка из макета, ждёт настоящих названий.
